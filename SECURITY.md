# Security Policy

## Supported Versions

Currently, only the latest major release of Auto-CTI is actively supported with security updates. 

| Version | Supported          |
| ------- | ------------------ |
| 1.x.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

Please **do not** report security vulnerabilities through public GitHub issues.

If you discover a security vulnerability within the Auto-CTI project, please responsibly disclose it by sending an email to **Abdullah Al Smadi** at `abdullahalsmadi2024@gmail.com`.

**What to expect:**
* You will receive an acknowledgment of your report within 48 hours.
* The issue will be investigated, and a timeline for a patch will be determined.
* Once the vulnerability is resolved and an update is released, you will be credited for the discovery (if you wish).

Thank you for helping keep this open-source academic project secure!
